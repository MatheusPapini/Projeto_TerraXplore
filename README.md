# TerraXplore

### Plataforma educativa sobre fenômenos da natureza

Projeto desenvolvido em equipe como parte da formação no Instituto PROA.

O TerraXplore é uma plataforma educativa, que tem como foco explicar e ensinar de forma interativa os fenômenos da natureza.

**Minha participação:**
- Desenvolvimento full-stack em equipe.
- Participação nas entregas incrementais do projeto.
- Utilização da metodologia Kanban.
- Colaboração na implementação de funcionalidades.

🔗 Repositório: *https://terraxplore.vercel.app/index.html*
